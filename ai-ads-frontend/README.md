User-facing app for the AI Ads Pipeline: guided flows for generating static (poster) and video ads.

## Status

Scaffolding stage — framework not yet chosen. Candidates under consideration: Next.js/React.

## v1 flows this app needs to support

- Onboarding (Individual vs Organisation, incl. Brand Questionnaire gate for Orgs)
- Poster Ad pipeline (template select -> configure -> draft review -> final -> download/share)
- Video Ad pipeline: Text -> Video, Text -> Storyboard -> Video (per-shot MCQ stepper), Image -> Video, Motion Poster
- Brand kit / active-product indicator for Organisation accounts with multiple products
